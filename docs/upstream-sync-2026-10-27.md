## 部署与数据库

本次未修改数据库实体、初始化逻辑或迁移 SQL，无需新增数据库迁移。此前 3.4.0 的 `sender_email` 迁移仍须保留；不要重复执行 ALTER TABLE 或重置数据库。

生产使用的 `mail-worker/wrangler.toml` 增加独立转发绑定：

```toml
[[send_email]]
name = "forward"
```

该绑定用于站内邮件转发到 Cloudflare 已验证的目标邮箱，与外部发信渠道 `email` 或 Resend 分开。使用 Resend 的实例无需启用 `email` 绑定；此更新也不会替换应用里已有的 Resend Token。

目标地址仍须在 Cloudflare 验证，并在应用中开启、配置转发规则。新增绑定本身不会开启转发或发送邮件。

## 验证与回退
